# Hero Background Images

This directory contains background images for the hero section on the homepage.

## Required Image

Please save your hero background image as:
- **Filename**: `hero-background.jpg`
- **Recommended size**: 1920x600px (or larger)
- **Format**: JPG or PNG

The image you provided should be saved here as `hero-background.jpg`.

## Current Usage

The hero background is used in:
- `src/app/[locale]/page.tsx` - Homepage hero section

The image is displayed with:
- Rounded corners (rounded-3xl)
- Gradient overlay: `linear-gradient(0deg, rgba(0, 0, 0, 0.45) 0%, rgba(0, 0, 0, 0) 40%)`
- Background size: cover
- Background position: center

## To Update

Simply replace the `hero-background.jpg` file with your new image.
