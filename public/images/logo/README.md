# Logo Directory

This directory contains the Pome logo files.

## Required Logo

Please save your pomegranate logo image as:
- **Filename**: `pome-logo.png`
- **Recommended size**: 256x256px or 512x512px (square)
- **Format**: PNG with transparent background (preferred) or JPG

The pomegranate logo you provided should be saved here as `pome-logo.png`.

## Current Usage

The logo is used in:
- `src/components/layout/header.tsx` - Main header/navigation

The logo is displayed at:
- Mobile: 28px (w-7 h-7)
- Tablet: 32px (sm:w-8 sm:h-8)

## To Update

Simply replace the `pome-logo.png` file with your new logo image.
